# Aset brand Pilem Studio

Logo: huruf **P** dengan batang berupa potongan pita film (3 lubang sprocket) dan tombol play di mangkuknya. Artinya "film yang siap tayang".

| File | Pakai untuk |
| --- | --- |
| `pilem-studio-icon.svg` | Sumber utama logo (vektor). Sama dengan `apps/web/public/icon.svg` dan komponen `apps/web/components/logo.tsx`. |
| `pilem-studio-icon-512.png` | Foto profil media sosial, ikon aplikasi, avatar channel. |
| `pilem-studio-wordmark-gelap.png` | Logo lengkap di latar gelap (banner, slide, header). |
| `pilem-studio-wordmark-terang.png` | Logo lengkap di latar putih (dokumen, invoice, proposal). |

Warna

| Nama | Hex |

Huruf: Bricolage Grotesque (judul & wordmark), IBM Plex Sans (teks), IBM Plex Mono (angka & timecode).

Jangan mengubah proporsi ikon, memutar, atau mengganti warna amber. Beri ruang kosong minimal setengah lebar ikon di sekelilingnya.
